# 📊 Трекер настроения (Mood Tracker)

Простое и стильное приложение для Android, которое помогает отслеживать твоё эмоциональное состояние каждый день. Выбирай своё настроение одним нажатием, и приложение само запомнит его. Смотри истории за последние 7 дней и анализируй свои эмоции.

---

## ✨ Особенности

- **😊 Быстрый выбор настроения** – 5 эмодзи на любой случай: радость, грусть, злость, нейтральное состояние или усталость.
- **📅 Автоматическое сохранение** – каждая запись привязывается к текущей дате и сохраняется локально на твоём телефоне.
- **📈 История за 7 дней** – удобный список с датами и настроением, который помогает увидеть динамику твоего состояния.
- **🎨 Современный тёмный дизайн** – мягкие карточки, аккуратные тени, приятная цветовая палитра.
- **⚡ Работает без интернета** – все данные хранятся в `SharedPreferences`, не требуется подключение к сети.

---

## 🚀 Как установить

1. Скачай последнюю версию APK-файла из раздела **Releases** на GitHub.
2. Установи файл на свой телефон (при необходимости разреши установку из неизвестных источников).
3. Открой приложение и начни отслеживать своё настроение!

---

## 🛠 Технологии

- **Язык:** Java  
- **Среда разработки:** CodeAssist / Android Studio  
- **Хранение данных:** `SharedPreferences` (локально, без интернета)
